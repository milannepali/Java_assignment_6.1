# Assignment 6.1 – Virtual Dictionary

I created a virtual dictionary application using JavaFX and the MVC model.

## Completed requirements

1. I created the Dictionary class using HashMap to store words and their meanings. It contains methods to add and search for words.

2. I created the DictionaryView class with a TextField, Button, and Label using FlowPane.

3. I created the DictionaryController class to handle word searches.

4. The application reacts when the user presses the Search button.

5. The application displays the correct meaning when a word is found.

6. The application displays an appropriate message when the input is empty or the word is not found.

## Testing

I tested existing words, unknown words, uppercase words, and empty input. The application worked correctly.

The dictionary data is temporarily hardcoded in the controller.
